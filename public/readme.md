# Static Assets Folder

Upload your two professional photos here to display them permanently on your website for all visitors:

1. **Primary Business Suit Photo**: 
   - Rename your file to `portrait_primary.jpg`
   - Upload it directly into this folder `/public/`

2. **Secondary Academic Chair Photo**:
   - Rename your file to `portrait_secondary.jpg`
   - Upload it directly into this folder `/public/`

Once uploaded, the website will automatically prefer these real photos over the fallback digital vector art!
